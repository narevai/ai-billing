Configuration for [createGoogleVertexV3Middleware](/sdk/ai-billing/reference/google-vertex/typedoc/functions/createGoogleVertexV3Middleware).

Extends BaseBillingMiddlewareOptions (`destinations`, `defaultTags`, `waitUntil`, `onError`) and
requires a PriceResolver. Usage is taken from Vertex's Gemini-native `usageMetadata` fields; cost
is computed from that usage and the resolved ModelPricing using the same rules as the package's
cost helper.
