# Interface: AzureV4MiddlewareOptions\<TTags\>

Defined in: azure/src/ai-sdk/language-model-middleware/v4/language-model-v4-azure-billing-middleware.ts:44

Configuration for [createAzureV4Middleware](/sdk/ai-billing/reference/azure/typedoc/functions/createAzureV4Middleware).

Extends BaseBillingMiddlewareOptions (`destinations`, `defaultTags`, `waitUntil`, `onError`) and
requires a PriceResolver. Usage is taken from the raw Responses-API usage payload when present,
falling back to the AI SDK's normalized usage fields otherwise; cost is computed from that usage and the
resolved ModelPricing using the same rules as the package's cost helper.
