Configuration for [createPerplexityV3Middleware](/sdk/ai-billing/reference/perplexity/typedoc/functions/createPerplexityV3Middleware).

Extends BaseBillingMiddlewareOptions (`destinations`, `defaultTags`, `waitUntil`, `onError`) and
requires a PriceResolver. Usage is taken from the AI SDK's normalized usage fields (falling back to
the raw provider usage payload); cost is computed from that usage and the resolved ModelPricing
using the same rules as the package's cost helper.
